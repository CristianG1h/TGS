# Teoría General de Sistemas

Sitio académico estático sobre la Teoría General de Sistemas. La portada explica entradas, salidas, procesamiento, retroalimentación y tipos de sistemas. Las páginas del curso organizan el material por cortes.

Abre [index.html](index.html) y navega por el [primer corte](Primercorte.html), el [segundo corte](segundocorte.html) y el [tercer corte](tercercorte.html). El sitio usa HTML, CSS y JavaScript. Mantén las carpetas de estilos e imágenes junto con las páginas al copiarlo.

La rama de trabajo del sitio es `many`.
